# Examples

Runnable projects wired up with Shipi18n. Each is self-contained — `cd` into one,
install, and run its `check` / `translate` scripts.

| Example | Stack |
|---|---|
| [react](./react) | Vite + React + react-i18next |
| [nextjs](./nextjs) | Next.js App Router |
| [vue](./vue) | Vue 3 + vue-i18n |
| [nodejs](./nodejs) | Node.js + `@shipi18n/core` |

> These previously lived in separate `shipi18n-*-example` repos; consolidated here
> (2026-09-13) so everything is in one place. The standalone repos are archived.
